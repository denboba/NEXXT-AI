Every hand-off in a classic funnel is a place where people drop out: the landing page does not speak to them, the brochure is generic, objections send them to a different channel, forms ask for data the bank partly already has, and the context is lost when they move from the website to the app. The design principle behind the coach is simple: never make the customer start over.
