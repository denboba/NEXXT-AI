Now the summit theme: where does AI actually create growth? Not in one place, but in four levers along the same conversation. Acquire: the ad lands in a conversation, and because the opening line is just a prompt, we can test new hooks and audiences in days instead of weeks. Convert: personal numbers plus answered objections, then onboarding that reuses what the person already told us. Activate: the plan is one tap away, and the first debit is scheduled while motivation is highest. Expand: the same coach serves existing clients and checks in monthly, which is where long-term value comes from. Each lever has one business metric it moves — we come back to these on the measurement slide.
